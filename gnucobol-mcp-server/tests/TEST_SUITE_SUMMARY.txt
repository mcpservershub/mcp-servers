🚀 QUICK START
================================================================================

1. Install GnuCOBOL:
   $ sudo apt-get install gnucobol

2. Setup Python environment:
   $ python3.12 -m venv .venv
   $ source .venv/bin/activate
   $ pip install -e ".[dev]"

3. Run all tests:
   $ pytest tests/test_gnucobol_mcp.py -v

4. Test with MCP Inspector:
   $ npx @modelcontextprotocol/inspector
